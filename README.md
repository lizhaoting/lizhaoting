# Hi, I'm Eric.

I build practical tools for AI agents, with a focus on structured data and workflows that need to hold up outside a demo.

## Projects

**[excli](https://github.com/lizhaoting/excli)**  
A Rust CLI for working with spreadsheets in scripts and agent workflows. It reads, filters, transforms, and aggregates spreadsheet data, and provides structured JSON output for downstream tools.

**[China Inbound Travel Skill](https://github.com/lizhaoting/china-inbound-travel-skill)**  
An Agent Skill project to help international visitors navigate travel in China across Codex, Claude, and other `SKILL.md`-compatible agents. It is currently in the research and requirements stage, with a focus on verifiable entry guidance, payments, rail travel, and practical fallbacks.
